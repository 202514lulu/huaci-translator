# 划词翻译 · 使用说明

选中任意软件里的文字，按一下热键，就地弹出中文译文。

- 全局生效：Word、PDF 阅读器、Zotero、浏览器、任何软件
- 不需要联网开关、不需要注册、不需要 API Key
- 中英双向自动识别：选英文出中文，选中文出英文
- 常驻右下角托盘，随开随用

---

## 一、启动

**双击桌面的 `划词翻译`**（快捷方式，图标是 Electron 的蓝色标志）

启动后不会有主窗口，只在右下角托盘出现一个蓝色「译」字图标 —— 这是正常的，程序在后台待命。

> **别双击 `.bat` 文件。** Windows 双击 `.bat` 会先弹出一个黑色命令行窗口，
> 而且那个窗口的当前目录就是 `.bat` 所在位置（桌面），看起来像"跳到桌面文件夹了"。
> 用 `.lnk` 快捷方式启动则完全没有控制台窗口。

## 〇、两种形态（都已验证可用）

| 形态 | 位置 | 说明 |
|---|---|---|
| **开发版** | 项目根目录 | 依赖 `node_modules`，改代码即时生效，适合以后调功能 |
| **独立版** | `dist\win-unpacked\` | 279 MB，含 `划词翻译.exe`，**不依赖任何开发环境**，可整个文件夹拷到别的电脑用 |

桌面快捷方式指向**独立版**（更稳）。

两个版本都实测通过自测：翻译成功、取词组件可用、热键注册成功。

> 项目里另有两个批处理启动器（`启动划词翻译.bat`、`dist\win-unpacked\启动.bat`），
> 仅供排查问题时看控制台输出用。日常使用请走桌面快捷方式。

要重建桌面快捷方式（比如换了电脑、或路径变了）：

```
python tools\make_lnk.py "dist\win-unpacked\划词翻译.exe" "%USERPROFILE%\Desktop\划词翻译.lnk" --read
```

会打印读回验证结果（目标 / 工作目录 / 图标是否都存在）。

## 二、怎么用

1. 在任意软件里**选中一段文字**（英文或中文都行）
2. 按 **`Alt + Shift + Z`**
3. 鼠标旁边弹出小窗，显示译文

弹出的浮窗上：

| 按钮 | 作用 |
|---|---|
| `⟳` | 重新翻译 |
| `⧉` | 复制译文到剪贴板 |
| `✕` | 关闭（或直接按 `Esc`） |

浮窗**双击正文区域也可关闭**。

---

## 三、改热键

右键托盘图标 → **设置** → 填新的热键 → 保存。

支持的写法（区分大小写不重要，但符号要准确）：

```
Alt+Shift+Z
Ctrl+Shift+T
Alt+Q
Ctrl+Alt+D
```

保存后立即生效，不用重启。

---

## 四、右键托盘能做什么

| 菜单项 | 说明 |
|---|---|
| 翻译当前选中/剪贴板 | 手动触发一次翻译（和按热键一样） |
| 热键：xxx | 显示当前热键 |
| 设置 | 改热键 |
| 打开数据目录 | 看配置文件和运行日志 |
| 退出 | 关闭程序 |

**双击托盘图标** = 手动触发翻译。

## 五、两种工作模式

程序会自动检测取词组件是否可用：

**完整模式**（本机已确认可用）
> 选中文字 → 按热键 → **自动复制并翻译**，一步到位。

**精简模式**（取词组件加载失败时自动降级）
> 先按 `Ctrl+C` 复制文字 → 再按热键翻译。

设置窗口里会显示当前处于哪种模式。

## 六、出问题时

### 窗口不弹出 / 没反应

1. 确认托盘图标还在（右下角小三角里找找）
2. 右下角时间旁边点开隐藏图标区域，看「译」字图标在不在
3. 重新双击桌面的 `划词翻译.bat`

### 提示"没有取到选中文本"

- 可能是选中的内容为空，或选区被其他程序占用了
- 退到精简模式：先 `Ctrl+C` 复制，再按热键

### 翻译结果是英文（没翻成中文）

- 说明它把内容判成了中文。检查一下是不是选中了中英混排的大段文字
- 中英混排时，中文字符超过一半会被判为中文，此时输出英文

### 想看运行日志

右键托盘 → **打开数据目录** → 看 `run.log`。

## 附：做便携版 exe

已配好 `electron-builder.json`，但由于沙箱不允许创建符号链接，
最后那个"单文件便携 exe"这一步会报错：

```
ERROR: Cannot create symbolic link : 客户端没有所需的特权。
```

**不影响使用** —— `dist\win-unpacked\` 已经是完整的独立程序了。若想要真正的单文件，
在普通用户会话里执行：

```
node_modules\electron\dist\electron.exe 无关
# 或直接：
npx electron-builder --win portable
```

```
│       └── settings.html   设置窗

```
